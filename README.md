# 将棋 (Shogi)

ブラウザで遊べる、AI対戦つきの単一ファイル将棋です。

**▶ 遊ぶ: https://tg2032.github.io/shogi/**

`shogi.html` をブラウザで開くだけでも動きます（サーバー・ビルド不要）。

## 機能

- 先手・後手を選んで AI と対戦（後手では盤を回転表示）。難易度は5段階（はじめて／やさしい／ふつう／つよい／とくにつよい）
- 持ち駒・成り／不成・二歩・打ち歩詰め・行き所のない駒の禁止
- 千日手（連続王手の千日手は反則負け）、入玉宣言（27点法）、256手で持将棋
- ヒント、待った、棋譜（右・左・直などの区別つき）、棋譜とKIFのコピー、座標表示、形勢バー、勝敗記録
- 自動保存と再開（待った履歴も復元）
- AI は Web Worker 上で動作（置換表・ヌルムーブ・静止探索・LMR など）
- キーボード操作、スクリーンリーダー、スマホ幅に対応

## 開発

エンジン部分は `shogi.html` 内の `<script id="engineSrc">` にあります。
依存なしのテストを Node.js（18+）で実行できます。

```bash
node test/engine.test.js
```

perft、ハッシュの整合、打ち歩詰め・二歩、強制成り、詰みの発見、入玉宣言、全難易度の自己対局を確認します。
